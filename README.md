Example of fitting a Bayesian model to the Doppler velocity coronal Power Spectrum. 

This shows a worked example of how to fit the data. In order to run it, you will need to download and process the data first.

The data is available at https://nso.edu/dkist/data-center/ with identifiers L1-EXJWQ, L1-FCHTW. You can use https://github.com/Richardjmorton/CRYOtools
to process the data.

This is associated. With a paper currently under review.
